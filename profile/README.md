# 🔬 NVJP Tech — Software Engineering Studio

> **"Transforming logic into impact, one line of code at a time."**

Bem-vindos ao perfil oficial da **NVJP Tech**. Somos um grupo de estudantes de **Engenharia de Software na FIAP**, unidos pelo propósito de construir soluções digitais robustas, escaláveis e de alto desempenho. 

Atuamos como uma startup fictícia de desenvolvimento, onde cada projeto é uma oportunidade de aplicar padrões de engenharia de nível empresarial para resolver dores reais do mercado e da sociedade.

## 💡 Nosso Propósito
Nosso objetivo é ir além do "funciona". Buscamos a excelência técnica através de **Clean Code**, **S.O.L.I.D.** e **Arquiteturas de Missão Crítica**. Não apenas escrevemos código; projetamos sistemas que sustentam o futuro.

*"A engenharia de software não é sobre construir o que é fácil, é sobre tornar o impossível escalável."*
